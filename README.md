## How to use Termux 
* cd "folder 📁"
* ls "show All folder and file"
* nano "Edit file script"
* mkdir "create folder"
* cp "copy file"
* du -sh * "show size file= MB"
* ifconfig "show ip "
* CTRL+X and Y "Save file exit"
* CTRL+C "Stop script or close"
* CTRL+D "Exit Termux App"
* pkg install "packages"
